## 实测中修复的兼容问题

1. PowerShell 7 的模块搜索路径传入 Windows PowerShell，导致官方安装器找不到 `Get-FileHash`。现在优先选择 PowerShell 7，Windows PowerShell 回退时清理该子进程的模块路径。
2. 已有 uv 引导 Python 目录发生链接冲突。现在把引导 Python 和缓存也放进本项目 `.runtime/`，未删除用户原有 Python。
3. Magpie CLI 只写裸模型名时，Hermes 可能保持默认供应商。现在加上 Magpie 路由前缀，并读取 `model.provider` 核对。
